# Design review C — 2026-09-03 — domain layer (`src/lab/core/semantic/`, skill engines, MCP servers, process pre-existing code, `review/`, `scripts/`)

Reviewer: `code-reviewer` agent. Claims verified by grep, by running the engine/semantic layer (timings measured), and byte comparison of the taxonomy copies.

## 1. Summary
Well-designed in its ideas (vocabularies-as-data, spec-by-reference, deterministic-vs-agent, one MCP facade per concern)
and unusually well commented on *why*. Debt is concentrated in three places: **the ArchiMate taxonomy is duplicated four
times with one copy already divergent**, **the semantic layer is rebuilt from scratch on every validation call (~1.7 s,
measured)**, and **the layer has no tests at all** although every deterministic piece runs offline.

## 2. Findings (ranked)
- **H1 HIGH · `validate_relations()` rebuilds the entire semantic layer per call (~1.7 s measured).** `archimate_engine.py`
  `_semantic()` constructs a fresh `SemanticService()` (re-parses taxonomy + 4,034-line matrix XML + workbooks, rebuilds the
  rdflib Dataset) every call; `to_xml()` calls it unconditionally, so validate+render each pay it, inside metered tool calls.
  Fix: `@functools.lru_cache(maxsize=1)` on `_semantic()`. Effort S. Safe now.
- **H2 HIGH · taxonomy exists four times; one copy diverged.** `src/lab/core/semantic/archimate/taxonomy.json` == skill
  `references/archimate-classification.json` byte-for-byte (no generator/symlink); engine `_TYPES` (type→layer) 100%
  redundant with the taxonomy; engine `_aspect()` disagrees with the taxonomy on **17 types** (Stakeholder,
  CommunicationNetwork, Path, DistributionNetwork, Location, Grouping, Junction → "Behaviour"; Gap) and it drives the coarse
  fallback validator. Refactor: one file (symlink as `skills/archimate-adoit` already is), derive `_TYPES`/aspect from
  `_TAXONOMY` with the two layout-only buckets (Service/Interface) computed on top. Effort M. Safe now.
- **H3 HIGH · `resolve_existing` uses the wrong identity and silently degrades to NEW.** Calls `_adoit_search_many(cfg["ba_headers"])`
  (README/CLAUDE.md say tool nodes use the Architect's identity; works only because the grant is team-scoped); `except
  Exception: return out` with no log/span/re-raise → any 401/outage/renamed tool yields `[]` → `NEW`. The one step that
  prevents ADOIT duplicates fails open invisibly. Fix: `ar_headers`; record `resolve.search_error` on the span and a
  `search_failed` flag in state so the approval summary says "ADOIT unreachable — treat NEW with suspicion". Effort S. Do now.
- **H4 HIGH · `workflow.py`: 535 lines, six executors closed over an untyped `cfg` dict, modes chosen by `os.environ` inside
  the nodes.** Nothing declares what an executor needs; no executor is callable in isolation; modes are Strategy-with-if.
  Refactor: frozen `RunContext` dataclass injected once; module-level `async def` executors taking `(ctx, state)`;
  `BA_MODES: dict[str, Callable]` resolved once in `build_workflow`. Effort L — one deliberate pass with the refactor.
- **M1 MEDIUM · `_setup_otel()` copy-pasted ×5** (host, three MCP servers, `run_via_gateway.py`) + MCP bootstrap ×3;
  `export_capabilities.py` imports a *private* `_setup_otel` from another script. Refactor: `src/lab/platform/otel.py: tracer(service,
  instrument_urllib=False)` and `src/lab/substrate/mcpserver.py: serve(mcp, service, port)`. Effort S. Safe now.
- **M2 MEDIUM · spec by value|JSON-string|ref implemented twice** (`adoit_mcp._load_spec` vs inline in `semantic_mcp`
  `semantic_validate_model`/`semantic_store_spec`, already diverged). Refactor: `shared/specref.load_spec(...)`. Effort S.
- **M3 MEDIUM · `archimate_engine.py`: 807 lines, five responsibilities** (model, validation, view catalogue, layout engine,
  invariant checker, XML writer, SVG renderer); `REL_STYLE` dict literal rebuilt inside `to_svg()` while
  `archimate_notation.py` exists to own notation. Refactor: move `REL_STYLE` + markers to notation (S); then split
  `layout.py` / `model.py` / writers (M).
- **M4 MEDIUM · `Registry` holds two incompatible kinds; callers type-sniff** (`hasattr(v, "classes")`). Refactor: an
  `Ontology` protocol implemented by `Vocabulary` and `SkosScheme`. Effort S.
- **M5 MEDIUM · layer/aspect/relationship enums hand-copied into four artefacts** (schema, `prompts/ba.md`, `vocab.RELATIONS`,
  engine `_REL_TYPES`); the `provenance` mismatch was a symptom. Schema `layer` enum omits `Other`. Refactor: substitute
  enum lines into the prompt from the schema at composition time; generate the schema relationship enum from `vocab`. Effort M.
- **M6 MEDIUM · two written contracts with zero enforcement.** `resolve.schema.json` describes what `resolve_existing`
  emits but the node never validates (four `setdefault`s); `doc_role.schema.json` has no step. Wire `Draft7Validator` into
  `resolve_existing` (reuse `_schema_errors`); delete/park `doc_role` until its step exists. Effort S.
- **M7 MEDIUM · `src/lab/substrate/review/app.py` Review mode is 116 lines of top-level statements** (untestable); sequential `if mode…
  st.stop()` dispatch; two dead legacy branches (`xml_path`, `svgs` — unproducible since `adoit_request_import` takes refs).
  Refactor: `_review_page()`, dict dispatch, delete legacy branches. Effort S.
- **M8 MEDIUM · `strict=True` hard-coded in `archimate_render`; `store` forces `standard_views: True`** → a layout-invariant
  violation on any auto view fails the whole run at the last step after all LLM spend, and the deterministic fallback calls
  the same tool. Expose `strict: bool` on the tool; when false return `violations` and surface them to the reviewer. Effort S.
- **L1 LOW · stale docstrings**: `adoit_mcp/server.py` header/tool list ("ADOIT:CE", `xml_path`, missing 3 tools); skill
  `references/adoit-import.md:56-59` still claims "REST 403 service not present on CE" (a wrong-probe claim CLAUDE.md
  corrected); `SKILL.md:71` "no working REST write API". Re-register the skill after editing.
- **L2 LOW · minor**: `Model.render` bare `open().write()`; f-string without placeholders (engine:735); `import re` inside
  `Vocabulary.classify()`; `consumer.py:71` `global _stop` never assigned.

## 4. Scale & migration walkthroughs
New element type: 6–8 edits today → one taxonomy file + notation keyed by type with a default. New source kind: 6 places
with an if/else in `_ba_message` → a parser Registry (`{kind: Parser}` with `read(ref) -> (text, images)`). **New business
process: 4 places** (`workflows.GROUPS`, a near-copy `consumer.py`, `railway.py`, the review app's hardcoded process name)
→ a **process registry** `PROCESSES = {"visio_to_archimate": ProcessSpec(group, run_once)}` deriving GROUPS, a generic
consumer, and the Submit dropdown — the highest-value structural change for the "two pilot processes" milestone. N workloads:
per-process stream keys derived from the registry. AF/Azure duplication to name (not yet remove): `runlog`/`workflowviz`
vs AF checkpointing/observability; the manual one-shot retry vs AF middleware; `_call_tools` fallback — mark as compensating
controls with a named deletion trigger. Packaging obstacle: every entrypoint `sys.path.insert`s; `adoit_mcp/server.py`
inserts the skill scripts dir → make the repo an installable package (`pyproject.toml`), engine as a real module the skill
re-exports. The `art://` + storage-mcp design is an excellent Blob seam.

## 7bis. OO / DDD / hexagonal (lens 10)
Verdict: the hexagonal picture is better than the SOLID findings suggested — `archimate_engine` imports no infrastructure,
`src/lab/core/semantic/` only rdflib + stdlib (one leak), `src/lab/substrate/artifacts.py` already IS a port with three adapters. Most work is
naming and enforcing what the code almost does.
- **O1 HIGH · `Model` is an anemic aggregate** — `Model.rel()` checks only the type name + declared endpoints; ArchiMate
  legality (the domain's defining invariant) is enforced in THREE places, none the aggregate (`validate_relations`
  advisory; `relrepair.check`; `ArchitectAccumulator` — the only one that rejects). Refactor: inject the vocabulary
  (`Model(..., vocabulary=, on_illegal="warn"|"reject")`) so `rel()` guards legality; accumulator + relrepair delegate.
  Do after wave 1 settles.
- **O2 HIGH · the `state` dict leaks three contexts** (Ingestion / EA-read / Modelling / EA-write); `state["path"]` is
  written and never read (dead); `store` mutates the domain spec with a rendering flag (`standard_views`). Refactor
  (same pass as H4): `SystemDescription`, `ExistingArchitecture` (with `search_failed` — fixes H3 by construction),
  `StagedModel` frozen dataclasses; `standard_views` becomes a render argument.
- **O3 MEDIUM · ubiquitous language drift** — endpoints `src/tgt` vs `from/to` vs `source/target`; type `type` vs
  `candidateType` vs `class_name`/`class`; grouping `domain` → `folder` → `<organizations>` → ADOIT group (four names);
  `behaviors` (US) beside `behaviour` (UK) in one schema. Read by LLMs, so every synonym is a wrong-key risk. Pick one
  word per concept at the two contracts (schemas + MCP signatures); translate ADOIT's `groupId`/`className` in one named
  adapter place. Coordinate with M5.
- **O4 MEDIUM · the one infra leak in the core**: `src/lab/core/semantic/reference/baguild.py` imports `openpyxl`, reads
  `REFERENCE_MODELS_DIR`, globs the filesystem, and `SemanticService.__init__` loads it eagerly (why construction costs
  1.7 s and tests need licensed workbooks). Refactor: `ReferenceModelSource` port; `XlsxWorkbookSource` adapter outside
  `src/lab/core/semantic/`; `SemanticService(reference_source=…)` default none. Safe now; compounds with H1 + tests.
- **O5 MEDIUM · ports exist unnamed** — `ArtifactStore` (declare the Protocol), `EARepository` read (`adoit_rest`),
  **`EAWritePath`** (Excel file-import live, REST dormant; today the "choice" only swaps a help string) → a Strategy
  chosen once at a composition root (`build_server(config)`); flipping to a write-capable tenant becomes config.
- **O6 LOW · domain events exist unnamed** (`approvals:*`, `workflow:*` streams; stringly statuses) — later (B's territory).
- **Keep simple**: `scripts/*` scripts (no layering); do NOT wrap `spec` in a class (it is the wire contract — put
  invariants in `Model`); no `DiagramRenderer` port (one renderer); no repository/UoW over `SemanticStore`; don't split
  `src/lab/core/semantic/` into layers (~700 pure lines); `src/lab/substrate/review/app.py` stays a Streamlit script.
- Revised quick wins: (1) `lru_cache` `_semantic()`, (2) dead code incl. `state["path"]`, (3) one taxonomy file, (4)
  `resolve_existing` `ar_headers` + `search_failed`, (5) `ArtifactStore` Protocol + lift `openpyxl`/glob/env out of
  `src/lab/core/semantic/reference/` (unblocks three of the four tests).
